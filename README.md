# forksession 🌳

> 内容驱动的四级会话分类与分支机制 —— 让 AI 助手上的每一条消息，都长在该长的树枝上。

forksession 是一个 **DSH（DeepSeek Harness）飞书插件**。它把飞书入口的全部消息自动分类到一棵 **L1→L4 会话树**上：同类话题永远续作同一片树叶，新话题按层次自动长出新叶——所有会话像树叶到树干一样**可分类、可追溯、可续接**。

> **v0.2 调度员架构**：调度从"插件算法"变回"agent 行为"——**主干是大脑，树叶是手脚**。

```
L1 主干：飞书总调度主会话（大脑: 索引目录式上下文, 恒 < 2 万 token）
└─ L2 树干：任务类型（开发 / 运维 / 查询 / 商业 / 法务 / 学习 …）→ 对应独立工作区
   └─ L3 树枝：领域（DSH插件开发 / 酒店尽调 / …）
      └─ L4 树叶：具体项目（forksession开发 / 海峡奥体全季 / …）→ 持久工作会话（手脚）
```

## 核心能力

- **调度员回路**：每条消息由主干 agent 决策分发——`[[STEER]]` 续作既有树叶 / `[[CREATE]]` 自动建叶 / `[[REPLY]]` 直接应答 / `[[MULTI]]` 复合拆解；执行结果回传主干汇总
- **索引目录式上下文**：主干每轮只见"活跃树叶索引"（id|名称|描述 打标格式，~1.3K 字符），不背全文——调度质量由树叶身份卡驱动
- **主干永不膨胀**：镜像改索引行、产出截断回传；超 2 万 token 自动压缩轮换——历史精炼进记忆文件（附索引快照），新代带记忆重生并自动热切
- **树叶记忆**：每片树叶一份记忆文件；长叶会话的旧轮次自动压缩回收进记忆，新会话带记忆重生（轮换机制主干/树叶通用）
- **树叶画布**：可视化看板——树形逐级钻取、路由脉冲实时直播、时间轴回放树的生长
- **治理安全**：归档会话只读不可自动触碰；外部渠道（CLI/headless）会话自动收编；v0.1 算法裁定链保留为纯兜底

## 调度协议

主干输出结构化指令块，插件解析执行：

```
[[REPLY]] 内容                                   → 直接回飞书
[[STEER]] {"sessionId":"叶id","text":"指令"}      → 叶会话执行 → 回传 → 主干汇总
[[CREATE]] {"l2":"树干","domain":"领域","topic":"事件","text":"指令"}
[[MULTI]]  [上述动作数组]                         → 复合消息逐项执行
```

## 快速开始

```bash
# 1. 安装依赖
npm install

# 2. 配置（真实值不进仓库）
cp config.example.json config.local.json
# 编辑 config.local.json: 飞书 appId / 授权用户 / 工作区路径…
export DSH_FEISHU_APP_SECRET=<你的飞书应用密钥>

# 3. 注册到 DSH profile
cp cordis.patch.example.yml cordis.patch.yml   # 按注释填写
# 以 patched profile 启动 dsh web 即可
```

## 飞书指令

| 指令 | 作用 |
|---|---|
| `/tree` | 查看四级分类树全景 |
| `/trace <sessionId>` | 单会话溯源（沿父链追根到主干） |
| `/fork <任务>` | 手动 fork 专项分支（继承主干上下文） |
| `/branches` | 列出活跃分支 |
| `/setmain <sessionId>` | 热切换 L1 主干会话（主干轮换时也走同一文件自动热切） |

其余一切（调度、建叶、续接、拆解、记忆、轮换）**全自动**。

## 项目结构

```
lib/
├── index.js             # 插件主体（调度回路/建叶/复合拆解/镜像/清扫/主干轮换）
├── session-registry.js  # 四级分类注册表（TAXONOMY + 动态节点 + 落位元数据）
├── leaf-memory.js       # 树叶记忆文件 + 压缩轮换 seed 构造（主干/树叶通用）
├── root-branch.js       # 分支存储与指纹匹配（2-gram Jaccard）
├── classify-rules.js    # L2 正则分类规则
├── agent-loop.js        # 轻量 LLM 调用（调度/语义路由/记忆压缩, 判定类定温 0.1）
├── context-manager.js   # 上下文 token 预算压缩
├── tools.js             # 工具层（文件/命令）
└── config.js            # 本地配置集中入口（脱敏边界）
```

## 隐私与脱敏

所有本地值（appId、用户 ID、会话 ID、路径）统一走 `lib/config.js`：
`config.local.json`（git 忽略）> 环境变量 > 占位默认。`appSecret` 仅存在于环境变量。
仓库内**不含任何真实本地信息**。
